# SentimentAI
### An AI-powered application that collects user feedback through a React frontend and uses Large Language Models to analyze and classify feedback sentiment  
**Tech:** React.js, Large Language Models, Java, Spring Boot, Spring AI, OpenAI models (GPT-4o), Tailwind CSS, MySQL, Axios.
